## Features by Role

### Waiter
- View table map with real-time status
- Create and manage orders
- Process payments and bills
- Access settings

### Kitchen
- View Kitchen Display System (KDS)
- Track order tickets (New → Preparing → Ready)
- View detailed ticket information
- Monitor preparation times

### Manager
- View dashboard with KPIs and analytics
- Monitor staff activity
- Generate reports
- Manage alerts and approvals

## Navigation Tips

- All roles can access Settings from the profile icon
- Use the back button to navigate between screens
- Logout from Settings page
- Tables can be clicked to view details and take actions
